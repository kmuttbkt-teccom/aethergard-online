# Midgard Story (MapleStory x Ragnarok Online MMORPG)

เกมออนไลน์เล่นบนเว็บเบราว์เซอร์แนว **2D Open World Action MMORPG** ที่ผสมผสานระบบ RPG สุดคลาสสิกของ **Ragnarok Online** เข้ากับแอ็กชันการต่อสู้กระโดดฟันและสไตล์ภาพ Chibi แสนน่ารักของ **MapleStory**

---

## 🌟 ฟีเจอร์เด่นในเกม (Features)

### 1. การผสมผสานระบบ MapleStory + Ragnarok Online
- **ระบบสเตตัส 6 สาย (Classic RO)**: อัปแต้มอิสระ `STR`, `AGI`, `VIT`, `INT`, `DEX`, `LUK` ส่งผลต่อค่า ATK, DEF, ASPD, Critical Rate, Cast Time และ Max HP/MP โดยตรง
- **สายอาชีพ (Job Progression)**: เริ่มต้นที่ **Novice** และเปลี่ยนสายอาชีพคลาส 1 ได้แก่ **Swordman, Magician, Archer, Thief, Acolyte, Merchant**
- **แอ็กชันแพลตฟอร์มเมอร์ (Maple Movement)**: วิ่ง, กระโดด 2 จังหวะ (**Flash Jump** กลางอากาศพร้อมควันเอฟเฟกต์), เกาะบันไดและเชือก, กระโดดทะลุลงแท่นแพลตฟอร์ม (`ลูกศรลง + Space`)
- **ระบบการต่อสู้และสกิล**: ฟันธรรมดา, สกิลแรงอย่าง **Bash** (ทำดาเมจ 250% มีแรงกระเด็น), ตัวเลขดาเมจเด้งสไตล์ MapleStory พร้อมตัวอักษร **CRITICAL!** สีทอง
- **ระบบมอนสเตอร์และดรอปไอเทม**: มอนสเตอร์น่ารัก (Poring, Fabre, Spore, Peco Peco และมินิบอส Baphomet Jr.) พร้อมดรอปเงิน Zeny, น้ำยา Red/Blue Potion, แร่ Jellopy และ **Poring Card** (ใส่ช่องอุปกรณ์)
- **ระบบเสียงสังเคราะห์ในตัว (Zero Dependencies)**: ใช้ Web Audio API จำลองเสียงเอฟเฟกต์ 8/16-bit ยุคทอง (ฟันดาบ, เลเวลอัป, เก็บเหรียญ, ดื่มยา) โดยไม่ต้องกังวลเรื่องไฟล์เสียงเสียหรือโหลดไม่ขึ้น

### 2. โหมด 3D ออนไลน์ (Three.js) — ระบบหลัก
กด **T** หรือปุ่ม **Mode** บนแถบเครื่องมือเพื่อสลับเข้าโหมด 3D ทุกระบบด้านล่างเซิร์ฟเวอร์เป็นผู้ตัดสิน (authoritative) ผู้เล่นทุกคนเห็นตรงกัน

- **ตัวละคร & อาวุธ 3D**: อาวุธ 11 ประเภท (มีด ดาบ ดาบสองมือ หอก ขวาน กระบอง เคียว คทาเวท คทาศักดิ์สิทธิ์ ธนู มือเปล่า) มีโมเดลในมือตัวละครจริง สีตามระดับความหายาก และเรืองแสงเมื่อตีบวก +7 ขึ้นไป ผู้เล่นคนอื่นเห็นอาวุธของเราด้วย
- **อาวุธมีผลต่อการเล่น**: ธนูและคทายิงระยะไกล (คทาใช้ MATK จาก INT, ธนูใช้ DEX), มีดโจมตีเร็ว, ดาบสองมือแรงแต่ช้า, หอกระยะไกลกว่าดาบ
- **สวมใส่อุปกรณ์**: 5 ช่อง (อาวุธ หมวก เกราะ รองเท้า เครื่องประดับ) มีเงื่อนไขเลเวลและอาชีพ คลิกไอเทมในกระเป๋าเพื่อสวม คลิกช่องอุปกรณ์เพื่อถอด
- **สกิล**: สกิลแยกตามอาชีพ (Novice มี First Aid) มีคูลดาวน์/MP ตรวจสอบฝั่งเซิร์ฟเวอร์, อัปเลเวลสกิลได้ถึง Lv.10 ในหน้าต่างสกิล, สถานะแช่แข็ง/มึนงง, เอฟเฟกต์ 3D (ลูกธนู ลูกไฟเวท อุกกาบาต ฝนแสง ระเบิดน้ำแข็ง ฯลฯ)
- **มอนสเตอร์ AI**: มอนสเตอร์โซน 1 จะสู้กลับเมื่อถูกตีเท่านั้น ตั้งแต่ป่า Aetherwoods ขึ้นไปจะไล่ล่าผู้เล่นทันทีที่เห็น มีหลอด HP ท่าพุ่งโจมตี และกรอบเป้าหมาย
- **ตาย & เกิดใหม่**: HP หมดจะตาย (Base Lv.10+ เสีย EXP 1%) แล้วเกิดใหม่ที่จัตุรัสเมือง Solaria พร้อม HP 50%, ฟื้นฟู HP/MP อัตโนมัติ (เร็วขึ้นเมื่อไม่อยู่ในการต่อสู้)
- **NPC ในเมือง Solaria**: Eldrin (พรเริ่มต้น), Bronn (ตีบวก), **Garrick (ร้านอาวุธ/เกราะ)**, Lyanna (ฮีล/บัฟ), **Cindy (ร้านยา — ซื้อ/ขาย)**, **Kaelen (อาชีพ/สกิล)**, **Sera (วาร์ปข้ามโซน)** — ต้องเดินเข้าใกล้ก่อนใช้บริการ อาชีพ Merchant ซื้อถูกลง 10% ขายแพงขึ้น 10%

ข้อมูลเกม (ไอเทม สกิล NPC ร้านค้า สูตรคำนวณสเตตัส) อยู่ในไฟล์เดียว `server/src/GameData.ts` ซึ่งทั้งเซิร์ฟเวอร์และไคลเอนต์ใช้ร่วมกัน

### 3. เทคโนโลยีที่ใช้ (Tech Stack)
- **Client**: TypeScript, Vite, Three.js (โหมด 3D), Phaser (โหมด 2D), โมเดล glTF/GLB + โมเดล procedural
- **Server**: Node.js, WebSocket (`ws`), Authoritative Game Room 30 Hz (AI มอนสเตอร์, ตรวจสอบความเร็วการเคลื่อนที่, คำนวณดาเมจ)

## 🚀 วิธีการรันโปรเจกต์ (How to Run)

### รันเซิร์ฟเวอร์และเข้าเล่นทันที:
```bash
npm start
```
จากนั้นเปิดเบราว์เซอร์ไปที่:
👉 **[http://localhost:4000](http://localhost:4000)**

*(หากต้องการเปิดหลายจอพร้อมกัน สามารถเปิด Tab หรือหน้าต่างใหม่เพื่อดูการเคลื่อนไหวแบบ Real-time Multiplayer ได้ทันที!)*

### หรือรันในโหมด Development (Hot Reloading):
```bash
# รันทั้ง Client และ Server พร้อมกัน:
npm run dev

# หรือแยกรัน:
npm run dev:server   # WebSocket Server บน Port 4000
npm run dev:client   # Vite Client บน Port 3000
```

> ⚠️ ไฟล์ `.js` ที่อยู่คู่กับไฟล์ `.ts` ถูกสร้างโดย `tsc` และเป็นไฟล์ที่ Vite/เซิร์ฟเวอร์โหลดจริง หลังแก้ไขโค้ด `.ts` ให้รัน `npm run build` ทุกครั้ง แล้วรีสตาร์ทเซิร์ฟเวอร์

## 🔐 ความปลอดภัยและการตั้งค่าเซิร์ฟเวอร์

| ตัวแปร (Environment) | ความหมาย |
| :--- | :--- |
| `ADMIN_PASSWORD` | รหัสผ่านบัญชี `admin` (ถ้าไม่ตั้ง และบัญชียังใช้รหัสเริ่มต้นเดิม เซิร์ฟเวอร์จะสุ่มรหัสใหม่และพิมพ์ไว้ในคอนโซลตอนเปิด) |
| `TOKEN_SECRET` | คีย์ลับสำหรับเซ็น token (ถ้าไม่ตั้ง จะสุ่มและเก็บไว้ที่ `server/data/token-secret.key`) |
| `ALLOW_MOCK_OAUTH=1` | เปิดปุ่ม Google/Facebook แบบจำลอง — **ใช้เฉพาะตอนพัฒนา** เพราะไม่ได้ยืนยันตัวตนจริง |

- สิทธิ์ GM มาจาก role ของบัญชี (`admin`/`gm`) เท่านั้น ชื่อที่ขึ้นต้นด้วย `GM_` / `Admin_` สงวนไว้ให้ผู้ดูแล
- เควส การนับจำนวนที่ฆ่า และรางวัล คำนวณที่เซิร์ฟเวอร์ทั้งหมด
- ตัวละครหนึ่งตัวเข้าเกมได้ทีละหนึ่งเซสชัน, มีการจำกัดความถี่ข้อความและขนาดข้อมูล
